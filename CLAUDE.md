# Claude · ликбез — правила работы над проектом

Веб-презентация для дизайнеров о Claude. Автор — Валерия (русскоязычный дизайнер).
Сайт: https://valerietolk.github.io/claude-demo/ (текущая версия — `/v9/`), GitHub Pages собирается из ветки `main`.

## Как общаться
- Всегда по-русски, простым языком, без технического жаргона. Обращение на «ты».
- В конце каждого раунда коротко: что сделано, что решил(а) сам(а), открытые вопросы.
- Если правка неоднозначная (например, «убрать», привязанное ко всей главе) — не удалять главу целиком, а спросить.

## Рабочий цикл (как было в прошлом диалоге)
1. Валерия оставляет комментарии на превью-артефакте https://claude.ai/artifact/HnaPQqYNNRmXV2tXV4ofZs и пишет «оставила комменты».
2. Читать их через ArtifactComments (`action: read`, листать `cursor`, длинные треды — по `thread_id`). Новые — сверху (по дате). Пометка «carried from an earlier version» = старые, обычно уже сделаны — сверяться с текущим текстом.
   Комментарии сами не приходят (подписка не работает) — всегда читать, когда она скажет.
3. Править `content/*.md` (тексты) и `v9/index.html`, `v9/figures.js` (вёрстка, 3D-фигуры).
4. Проверить самому в headless-браузере (см. «Проверка»), до того как отдавать.
5. Коммит и пуш в ДВЕ ветки: `git push -u origin main-g8poi2 && git push origin main-g8poi2:main`.
6. Пересобрать превью `python3 tools/build_preview.py <scratchpad>` → `claude-seven.html`, прогнать `tools/smoke_preview.js`, опубликовать Artifact-ом В ТОТ ЖЕ url (`url: https://claude.ai/artifact/HnaPQqYNNRmXV2tXV4ofZs`; перед первой публикацией в новом диалоге сделать `Artifact action: read` этого url).
7. Отчитаться по-русски.

## Правила Валерии (обязательны)
- Тексты — ЕЁ. Не переписывать без согласия. Текст из комментария вставлять дословно, исправлять только опечатки и говорить, какие.
- Перед крупными изменениями — бэкап версии веткой `backup-...` (теги пушить нельзя). Есть: backup-figma-style, backup-v1, backup-v3-star, backup-v7-donut, backup-v8-figures, backup-v9-shapes.
- Цвет текста #0B0F19 (`--ink`). Все заголовки жирные. Иерархия: H1 > H2 (28px) > H3 (24px) > H4 (20px), единообразно.
- Без эмодзи (режутся при рендере), без разделителей/линеек, без пометок «Вау:».
- Callout (`<p class="callout">`) = стеклянная плашка (var(--glass) + blur) с красным свечением; без анимации рамки на hover (только лёгкий подъём).
- `.fact` — оранжевая полоса #FF5A14 со свечением.
- `<b>`/`<strong>` в тексте — font-weight 600.

## Устройство
- `content/01..12-*.md` — главы (ликбез, где живёт, chrome, Claude Design, Claude Code, connectors, skills, ограничения, ставим задачу эффективно, inspo, от себя, thanks). marked.js парсит их на лету. Глава thanks не в навигации и счётчиках («NN / 11»).
- `v9/index.html` — страница: hero-лого, главы, справа рейл с точками, «капля»-индикатор, бургер с оглавлением. Палитры чередуются по 7 равным участкам скролла: ORANGE / BLACK / ORANGE / BLACK / ORANGE / BLACK / ORANGE.
- `v9/figures.js` — Three.js r128, 7 живых 3D-фигур (по одной на участок): 0 звезда оранжевая с кремовыми пятнами («идеально»); 1 чёрная ветка с оранжевым мхом; 2 оранжевый мех, гнётся от курсора; 3 чёрная «гроздь» с оранжевыми пятнами; 4 нежно-персиковый «бублик» из шаров; 5 чёрная многолапая с кончиками («идеально»); 6 финальная звезда (копия 0). Фигуры 0 и 5 не трогать без просьбы.
- Корневой `index.html` — исходный стиль из Figma; `v7/`, `v8/` — старые версии, не удалять.

## Проверка
- Playwright: `NODE_PATH=/opt/node22/lib/node_modules node ...`, запуск chromium с `--use-gl=swiftshader --enable-webgl --ignore-gpu-blocklist`.
- Локальный сервер: `nohup python3 -m http.server 8765 &` в корне (иногда падает — перезапустить).
- `tools/walk_v9.js <папка>` — 7 скриншотов по участкам; `tools/smoke_preview.js <папка>` — проверка собранного превью (ошибки должны быть `[]`, секций 12).
