# claude-demo

Презентация о Claude в виде одной HTML-страницы: стартовый экран, сайдбар-роадмэп и слайды.
Макеты в Figma: https://www.figma.com/design/fdZWtMD7Ent4QsvhqBf0vU/claude

## Структура

- `content/*.md` — текст слайдов, по файлу на слайд. Здесь идёт вся редактура.
  - `# ...` — заголовок слайда, следующий за ним `## ...` — оранжевый подзаголовок.
  - `### ...` — раздел; эти заголовки появляются подпунктами в сайдбаре.
  - `> «...»` — промпт.
  - `<aside class="draft">` — черновик или след переписки, подсвечен пунктиром до валидации.
- `app.js` — список слайдов (массив `SLIDES`) и навигация: клик по шагу, ← →, ссылки вида `#code`.
- `index.html` — стартовый экран и каркас.
- `styles.css` — стили, фон с анимированными фигурами, степпер.
- `vendor/marked.min.js` — парсер Markdown.
- `fonts/` — сюда можно положить `LORE-Cyrillic.woff2` для заголовков. Без файла подставится Neucha.

## Запуск локально

```bash
npx http-server -p 5173 -c-1
```

Открывать через сервер: как файл (file://) страница не загрузит слайды.
