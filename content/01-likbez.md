## Claude - AI у которого появились руки

Claude — ИИ от Anthropic, который не просто отвечает в чате, а умеет действовать: ходить по сайтам, работать с файлами, взаимодействовать с Figma, писать код, создавать прототипы и запускать задачи самостоятельно.

Ты ставишь задачу: <s>раб</s> Claude идёт и делает.

Во что умеет:

- Исследовать: конкуренты, интервью, отзывы, ресёрч с источниками.
- Проектировать: первые концепции, wireframes, прототипы, пользовательские потоки.
- Критиковать: design critique, ux writing, accessibility audit.
- Систематизировать: дизайн-системы, компоненты, токены, состояния и правила.
- Проверять: юзабилити, доступность, консистентность, соответствие макета системе.
- Создавать: живые прототипы, мини-приложения, рабочие интерфейсы, слайд и питч-деки, анимации.
- Автоматизировать: рутинные задачи, отчёты, сбор данных и регулярный ресёрч.

### Ресёрч

- **Синтез интервью.** 10 расшифровок → боли пользователей с дословными цитатами, частотой и противоречиями между респондентами. <span class="tag">чат</span>
- **Отзывы тысячами.** Выгрузка 2000 отзывов из сторов → группы проблем, топ жалоб, примеры. Можно поставить на расписание: каждую неделю свежая сводка. <span class="tag">чат / расписание</span>
- **Конкуренты вживую.** Claude сам проходит онбординг или оплату у конкурентов в браузере, скриншотит каждый шаг и собирает сравнительную таблицу. <span class="tag">Chrome</span>
- **Исследование с источниками.** «Как банки решают подтверждение платежа, какие есть стандарты доступности» → отчёт со ссылками. <span class="tag">чат, режим Research</span>

### Постановка и решения

- **Разбор ТЗ.** «Найди дыры и противоречия, составь вопросы продакту» до того, как ты начала рисовать. <span class="tag">чат</span>
- **Все состояния экрана.** Загрузка, ошибка, пусто, длинные имена, нет прав, офлайн — всё, что обычно вспоминают на ревью. <span class="tag">чат</span>
- **Флоу в FigJam.** Описание словами → готовая схема пути пользователя с ветками ошибок прямо в FigJam. <span class="tag">Figma</span>
- **Направления, а не один вариант.** Три принципиально разных решения, затем разбор каждого глазами строгого арт-директора. <span class="tag">чат</span>

### Макет

- **Критика макета.** Скриншот или ссылка → проблемы юзабилити и доступности с объяснением и приоритетом. <span class="tag">чат / Figma</span>
- **Аудит файла Figma.** Находит цвета и отступы, заданные вручную вместо токенов, отвязанные компоненты, расхождения с дизайн-системой. <span class="tag">Figma</span>
- **Сборка экранов в Figma** из вашей библиотеки компонентов, а не из воздуха. <span class="tag">Figma</span>
- **Тексты интерфейса** в вашем тоне, с вариантами и проверкой, влезет ли немецкий перевод в кнопку. <span class="tag">чат / проект</span>

### Прототип

- **Живой прототип по ссылке:** настоящие данные, анимации, состояния. Можно сразу нести на юзабилити-тест. <span class="tag">Design / Code</span>
- **Claude Design:** прототипы и мокапы в вашей дизайн-системе. Мелкие правки делаются ползунками и перетаскиванием, дальше экспорт или передача в разработку. <span class="tag">Design</span>

### Передача и контроль

- **Спецификация для разработки:** состояния, поведение, тексты, крайние случаи. <span class="tag">чат</span>
- **Сверка вёрстки с макетом.** Claude открывает готовую страницу, сравнивает с Figma и выдаёт список расхождений. <span class="tag">Chrome / Code + Figma</span>

### Команда и рутина

- **Командный стандарт.** Ваш чек-лист дизайн-ревью записывается один раз, и Claude проводит ревью одинаково для всех. <span class="tag">скилл</span>
- **Инструменты для команды по ссылке:** голосовалка за концепты, база инсайтов, генератор текстов в вашем тоне. <span class="tag">артефакт</span>
- **Рутина с файлами:** переименовать 500 ассетов, выгрузить все тексты из макетов в таблицу для переводчиков. <span class="tag">Code / Cowork</span>
- **Слайды для стейкхолдеров** из результатов ресёрча. <span class="tag">Slides / Design</span>
