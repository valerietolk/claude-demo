### Облачная сессия Claude Code

<aside class="draft">Ты права, «запусти в облаке» звучит просто, а на деле там есть несколько важных деталей. Разберу по порядку.</aside>

#### Что это

Обычно Claude Code работает на твоём компьютере. Облачная сессия — тот же Claude Code, но на компьютере Anthropic в интернете: для каждой задачи создаётся отдельный виртуальный компьютер.

Что это даёт:

- ноутбук можно закрыть или выключить, задача продолжит работать;
- следить и отвечать на вопросы Claude можно с любого устройства;
- можно запустить несколько задач сразу, каждая в своём облачном компьютере.

#### Откуда запускать

- **С телефона:** приложение Claude → вкладка Code.
- **Из браузера:** claude.ai/code.
- **Из десктоп-приложения:** при создании сессии выбрать Cloud вместо Local. А уже идущую на компьютере сессию можно отправить в облако через меню «Continue in».

#### Главное условие: проект должен лежать на GitHub

Облачный компьютер не видит файлы на твоём ноутбуке. Он берёт проект из репозитория на GitHub.

Что сделать один раз:

1. Завести аккаунт на GitHub (бесплатно).
2. При первом запуске облачной сессии подключить GitHub, приложение само проведёт по шагам.
3. **Лайфхак для дизайнера:** заведи один репозиторий-песочницу, например «prototypes». Все шальные мысли из метро запускай туда, и не нужно каждый раз думать, куда класть.

#### Как выглядит сценарий «мысль в метро»

1. Открываешь приложение Claude на телефоне → Code → выбираешь репозиторий «prototypes».
2. Надиктовываешь задачу голосом: «Сделай прототип экрана подписки: три тарифа, переключатель месяц/год, анимация выбора…»
3. Убираешь телефон. Claude работает сам.
4. Если у него появится вопрос, придёт уведомление, ответишь там же. Не ответишь — через какое-то время сессия «уснёт», но ничего не потеряется: откроешь позже, и она продолжит с твоего ответа.
5. Дома открываешь сессию и смотришь, что получилось.

#### Как посмотреть результат

Это главный нюанс для дизайнеров: в облаке нет «окошка с превью», как на компьютере. Результат — это файлы в репозитории.

Варианты:

- Попроси в самой задаче: «в конце опубликуй прототип так, чтобы его можно было открыть по ссылке». Claude может настроить публикацию, например через GitHub Pages.
- Забери сессию на компьютер и открой прототип там, со всей историей переписки.

#### Лимиты и деньги

- Облачные сессии тратят тот же лимит подписки, что и всё остальное. Отдельной платы за облачный компьютер нет.
- Три задачи параллельно — тройной расход.
- В конце сентября Anthropic объявили, что облачные сессии доступны всем, и дали временный бонусный кредит ($100 на Pro, $250 на Max). Если актуально для тебя, проверь в настройках, пока акция не закончилась.

#### Кому доступно

Pro, Max, Team, а в Enterprise — премиум-местам. На Team облачные сессии может выключить админ. Если не работает, вопрос к нему.

#### Безопасность

Проект копируется на серверы Anthropic. Для песочницы с прототипами это не проблема, а код продукта и макеты под NDA — только если политика компании разрешает.

#### 2. Сложные SVG-фильтры (жидкое стекло)

Сами SVG-фильтры работают везде давно. Но эффект «жидкого стекла» с преломлением того, что под элементом (как в Apple Vision Pro или iOS 26) делается связкой, которая полноценно работает только в Chrome. В Safari (иронично, у Apple) и Firefox получится только обычное размытие.

Плюс производительность: такие фильтры на большой площади или в анимации ощутимо грузят слабые устройства.

<p class="fact"><b>Вывод:</b> стекло с размытием — можно. «Настоящее» жидкое стекло с преломлением — пока только как вау-концепт или с запасным вариантом для остальных браузеров.</p>

#### 4. WebGL

Вот это уже территория почти 3D.

**Что это?** WebGL позволяет использовать видеокарту браузера для сложной графики. Например:

- 3D-модели;
- интерактивные сцены;
- частицы;
- сложные эффекты.

**Пример.** Сайт Tesla. Ты открываешь страницу машины:

- крутишь автомобиль;
- меняешь цвет;
- камера плавно летает вокруг.

Это может использовать WebGL.

**Почему Claude осторожен?** Потому что WebGL:

- сложнее разрабатывать;
- сложнее тестировать;
- тяжелее для устройств;
- требует специальных знаний.

Для сайта продукта это иногда оправдано.

Для обычного лендинга с кнопкой "Купить" — это просто дизайнерский фейерверк, который пришёл без приглашения.
