# connectors

Коннектор даёт Claude доступ к сервису: Figma, Jira, Notion, аналитика, записи созвонов. Claude становится клеем между сервисами, которые друг с другом принципиально не разговаривают.

Через коннектор Claude умеет:

- создавать новые файлы Figma Design, FigJam и Slides с нуля
- писать в файл: компоненты, варианты, переменные, Auto Layout
- создавать шейдеры и генеративные плагины прямо в файле
- читать и ставить анимацию на ноды, экспортировать видео
- собирать диаграммы в FigJam из Mermaid
- Code Connect
- искать по дизайн-системе и доставать определения переменных

### Связки

#### 1. От интервью до доски <span class="tag">Zoom/Granola/Fireflies + Figma</span>

> «Возьми записи всех интервью за эту неделю, найди боли с цитатами и собери аффинити-карту в FigJam».

Провели интервью – наутро доска с кластерами готова.

#### 2. Паттерны → варианты в вашей системе <span class="tag">Mobbin + Figma</span>

> «Найди на Mobbin, как 10 приложений делают подтверждение платежа. Выбери 3 лучших подхода и собери каждый в Figma из наших компонентов».

#### 3. Ревью макета → задачи <span class="tag">Figma + Jira/Linear</span>

> «Сравни макет с тем, что сверстали, и заведи задачу на каждое расхождение, со ссылкой на фрейм».

#### 4. Спецификация сама собой <span class="tag">Figma + Confluence/Notion</span>

> «Сделай из этого фрейма страницу спецификации: состояния, поведение, тексты, крайние случаи, ссылки на макет».

#### 5. Результаты эксперимента → следующая итерация <span class="tag">Amplitude + Figma</span>

> «Вот A/B-тест на странице тарифов. Какой вариант выиграл, на каких сегментах, и что поменять в макете дальше?»

#### 6. Вернулись из отпуска <span class="tag">Slack + Jira + Figma</span>

> «Что произошло с редизайном корзины за последние 2 недели? Решения из Slack, изменения задач в Jira, новые комментарии в Figma. Что ждёт моего ответа?»

#### 7. Еженедельный пульс команды <span class="tag">Intercom + Amplitude + Slack, по расписанию</span>

> «Каждый понедельник собирай: топ-5 жалоб из поддержки, изменения ключевых метрик, и публикуй сводку в #design».
